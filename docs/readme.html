DNO Tool

Приложение для удалённого администрирования компьютеров на Linux (MOS/ALT) и Windows через SSH. Позволяет выполнять команды на десятках машин одновременно, передавать файлы, мониторить состояние устройств и управлять конфигурациями - всё из одного окна.

О программе

DNO Tool предназначен для системных администраторов, которым нужно управлять парком рабочих станций. Для команд и передачи файлов достаточно настроенного SSH-доступа. Для просмотра и управления экраном на удалённом компьютере дополнительно нужен Veyon или VNC-сервер.

Основные возможности:

  • Управление пакетами, службами, пользователями на удалённых машинах
  • Мониторинг ресурсов, сети, дисков, логов
  • Настройка безопасности: SELinux, SSH, аудит, firewall
  • Передача файлов по SFTP, установка SSH-ключей
  • Удалённая запись экрана (FFmpeg и GStreamer)
  • Мониторинг экранов через Veyon: живые миниатюры, просмотр и управление
  • Доступ к экранам через VNC (x11vnc) и KRFB: просмотр и управление из krdc или браузера
  • Карта сети: граф топологии с подсетями, маршрутами и роутерами
  • Нарезка и склейка записей во встроенном видеоредакторе
  • Пользовательские панели с кнопками частых команд в один клик
  • Настройка KDE/Plasma на рабочих станциях
  • Сканирование сети, проверка доступности устройств

Установка

ТребованиеМинимум
ОС (администратор)Windows 10+ или Linux
ОС (целевые машины)Любой Linux с SSH-сервером
Сетевой доступSSH (порт 22) до целевых машин

Windows

  1. Скачайте dno-tool-X.X.X-windows.zip с релиза на GitHub
  2. Распакуйте в удобную папку
  3. Запустите dno-tool.exe

Linux (RPM)

  1. Скачайте пакет RPM для вашей версии МОС (12 или 13) с релиза
  2. Установите: sudo dnf install ./dno-tool-*.rpm
  3. Запустите через меню приложений или dno-tool
Для работы программы необходимо, чтобы файл commands.json находился в директории ~/.dno-tool/. Загрузите библиотеку на шаге «Команды» мастера настройки или импортируйте свой файл. Обновление программы не заменяет вашу библиотеку.

Первый запуск

Настройки и пользовательские данные хранятся в директории ~/.dno-tool/ (файлы появляются по мере настройки и сохранения):

ФайлНазначение

hosts.jsonСписок устройств
commands.jsonБиблиотека команд
dno-tool.logФайл логов

Если при первом старте у вас нет ни списка устройств, ни списка команд, автоматически запустится мастер первоначальной настройки - он проведёт вас по всем шагам (см. ниже).

Для начала работы нужно:

  1. Добавить хотя бы одно устройство (см. ниже)
  2. Указать IP-адрес/hostname и связку учётных данных для SSH-доступа
  3. Отметить устройство галочкой, выбрать команду и нажать Выполнить

Системный трей

DNO Tool может работать в фоновом режиме, сворачиваясь в системный трей. Это удобно при длительных операциях (выполнение команд на десятках машин, запись экрана, мониторинг): окно можно спрятать, а программа продолжит работу.

Поведение

  • Закрытие окна (крестик или Alt+F4) - скрывает окно в трей, приложение остаётся работать в фоне
  • Клик по иконке трея - показывает/прячет окно
  • Контекстное меню трея - пункты «Открыть» (показать окно) и «Выход» (полностью закрыть приложение)
  • Тултип - показывает название и версию приложения

Индикатор занятости

Иконка трея отражает состояние приложения:

Добавление устройств

DNO Tool предоставляет несколько способов добавления устройств - от ручного ввода до автоматического сканирования сети.

1. Вручную

  1. Правый клик по дереву устройств или папке - Добавить устройство
  2. Заполните поля: имя, IP-адрес, связка учётных данных, порт (по умолчанию 22)
  3. При необходимости укажите MAC-адрес
  4. Нажмите Сохранить

Устройство будет добавлено в выбранную папку или в корень дерева.

2. Диапазон IP-адресов

Правый клик по дереву - Добавить диапазон IP. Позволяет массово создать устройства для целой подсети.

Поддерживаемые форматы:

ФорматПримерРезультат
CIDR192.168.1.0/24254 адреса
Короткий диапазон192.168.1.1-1515 адресов
Полный диапазон192.168.1.1-192.168.1.254254 адреса
Один IP192.168.1.1001 адрес

Диалог позволяет задать префикс имени (по умолчанию host), порт и связку учётных данных. Имя каждого устройства формируется как префикс-N - сквозная нумерация с единицы (например, host-1, host-2, …), что исключает дубликаты имён для подсетей больше /24. Максимально 1024 адреса за один раз.

3. Drag-and-drop текстового файла (.txt)

Перетащите .txt файл из проводника на дерево устройств. Программа прочитает файл и создаст устройства. Форматы строк (определяются автоматически):

РазделительФормат строкиПример
Без разделителятолько IP или hostname192.168.1.10
Запятаяname,host,port,macserver1,192.168.1.10,22,00:11:22:33:44:55
Двоеточиеname:host:port:macserver1:192.168.1.10:22:00:11:22:33:44:55
Точка с запятойname;host;port;macserver1;192.168.1.10;22;00-11-22-33-44-55
Tabname host port macserver1 192.168.1.10 22 00:11:22:33:44:55
Пробелыname host port macserver1 192.168.1.10 22 00:11:22:33:44:55

Поля port и mac необязательны - если их нет, порт берётся из настроек. Учётные данные задаются связками (см. Настройки), а не в строке импорта. Строки, начинающиеся с #, пропускаются как комментарии. Устройства добавляются в папку, на которую был сброшен файл.

4. Drag-and-drop текста

Вы можете скопировать текст из любого источника (таблица, терминал, документ) и перетащить его прямо на дерево устройств. Каждая строка разбирается по тем же правилам, что и текстовый файл.

5. Импорт JSON-файла

Через меню Файл - Хосты - Импортировать список можно загрузить устройства из JSON-файла. Формат файла аналогичен hosts.json.

6. IP-сканер

Через Инструменты - Сканер хостов можно автоматически обнаружить устройства в сети (см. раздел IP-сканер). Найденные устройства добавляются кнопкой Добавить выбранные.

7. Внутренний drag-and-drop

Устройства и папки можно перетаскивать мышкой внутри дерева для изменения структуры. Если перетащить устройство на другое устройство, целевое устройство автоматически станет папкой.

8. Двойной клик

Двойной клик по устройству открывает диалог редактирования. Двойной клик по папке - диалог переименования.

Управление устройствами

Дерево устройств

Устройства отображаются в виде иерархического дерева слева. Вы можете:

  • Создавать папки - через контекстное меню (правый клик)
  • Перетаскивать устройства между папками внутри дерева
  • Контекстное меню - правый клик: добавить, редактировать, удалить, пинг
  • Отмечать галочками устройства для добавления в список выполнения

Список выполнения

Устройства, отмеченные галочкой в дереве, появляются в списке справа. Именно этот список используется при выполнении команд. Можно отметить несколько устройств для массового выполнения.

Группы устройств

В режиме «Список» и «Иконки» устройства отображаются по группам - по папкам из дерева или по сетевым подсетям. Заголовок каждой группы интерактивен:

  • Клик по заголовку сворачивает или разворачивает содержимое группы. Рядом с названием показывается уголок-индикатор: ▾ - развёрнуто, ▸ - свёрнуто
  • Счётчик «онлайн/всего» - бейдж рядом с названием группы (например 3/5). Обновляется в реальном времени при изменении статуса устройств, при добавлении и удалении
  • Авто-сворачивание пустых групп - при включённом фильтре «только онлайн» группы без доступных устройств сворачиваются автоматически. Когда в свёрнутой группе появляется онлайн-хост, она разворачивается обратно. Ручные сворачивания пользователя при этом не сбрасываются

Секции списка прижаты кверху, а свободное место уходит вниз - так все группы собраны вместе и не растягиваются по всему окну.

Файловый командер

Двухпанельный файловый командер для обмена файлами между вашим компьютером и удалённым сервером. Открывается командой Обмен файлами в контекстном меню устройства.

Интерфейс

  • Левая панель — локальная файловая система, правая — удалённый сервер. Каждая панель имеет собственный тулбар и адресную строку с навигацией по сегментам пути
  • Тулбар панели: домой, назад, вперёд, вверх, обновить, создать папку, создать файл, скачать/загрузить, удалить, переименовать, копировать путь
  • Адресная строка показывает путь в виде хлебных крошек — клик по сегменту переходит в соответствующую папку. Кнопка ✏ переключает в режим ручного ввода пути
  • Диск-селектор (Windows, локальная панель) — переключение между дисками в одной строке с адресом
  • Статус-бар внизу показывает ход операций с прогресс-баром и кнопкой отмены. При перетаскивании файлов виден живой прогресс: текущий файл, проценты, размеры и скорость, а идущая операция помечена бейджем на окне

Перетаскивание файлов

  • Между панелями — перетащите файлы из одной панели в другую для загрузки или скачивания
  • Внутри панели — перетащите файлы в папку для перемещения
  • Из Windows Explorer — перетащите файлы из проводника в локальную панель для импорта или в удалённую для загрузки на сервер

Контекстное меню

Правый клик по файлу или папке открывает меню с действиями:

  • Открыть — предпросмотр файла (на удалённом сервере)
  • Упаковать в tar.gz — создать архив в текущей папке
  • Распаковать — распаковать архив (tar, zip, 7z, rar) в текущую папку. На удалённом сервере распаковка выполняется напрямую через SSH
  • Переименовать, Удалить
  • Копировать имя, Копировать путь
  • Свойства — информация о файле, редактирование прав доступа

Правый клик по пустому месту — создать папку, создать файл, обновить, копировать путь текущей папки.

Мониторинг доступности

Программа автоматически проверяет доступность отмеченных устройств. Когда вы ставите галочку рядом с устройством, программа начинает периодически проверять, доступен ли этот хост.

Как работает проверка

Проверка выполняется путём TCP-соединения к SSH-порту устройства (по умолчанию 22). Это не ICMP-ping - программа проверяет, работает ли SSH-сервис на хосте.

  • Интервал проверки - настраивается (по умолчанию 30 секунд, с разбросом +/-10% для равномерности нагрузки)
  • Таймаут соединения - настраивается (по умолчанию 2 секунды)
  • Порт проверки - совпадает с SSH-портом устройства (можно указать другие порты в настройках)

Результат отображается иконкой рядом с устройством:

  • Зелёная иконка - порт открыт, устройство доступно
  • Красная иконка - порт закрыт или хост недоступен

Проверка запускается автоматически при установке галочки и останавливается при снятии. Также проверка останавливается при удалении устройства или закрытии программы.

Для детальной диагностики сети с ICMP-ping и графиком задержки в реальном времени используйте Пингер.

Настройка портов проверки

В настройках приложения можно указать порты для проверки доступности. По умолчанию проверяется только порт 22 (SSH). Можно добавить порты 80, 443, 3389 и другие.

Запись экрана

DNO Tool позволяет удалённо записывать экран или камеру устройств через два движка:

FFmpeg

  • Захват экрана (x11grab, gdigrab), камеры (v4l2, avfoundation)
  • Протоколы: TCP, UDP, HTTP, RTSP
  • Автоматический перезапуск при обрыве

GStreamer

  • Захват экрана (ximagesrc), камеры (v4l2)
  • RTSP-сервер или TCP-поток
  • Кодеки: x264, x265, MPEG2, MPEG4
  • Автоустановка GStreamer-пакетов

Для записи выберите устройство, правый клик - Удалённая запись. Укажите параметры захвата, кодек и транспорт, затем нажмите «Старт».

Видеоредактор использует встроенный медиадвижок. При ошибке откройте Помощь → Инструменты → FFmpeg и проверьте результаты диагностики.

Работа с командами

Выбор и выполнение команды

Команды организованы в иерархические категории. Отметьте устройства галочками в дереве, выберите команду из выпадающего списка и нажмите Выполнить.

  1. Отметьте одно или несколько устройств галочками в дереве
  2. В выпадающем списке задач разверните нужную категорию и выберите команду
  3. Если команда требует параметров - появится диалог ввода значений
  4. Нажмите Выполнить
  5. Результаты появятся в таблице внизу окна
Команды выполняются параллельно на всех выбранных устройствах. Выполнение можно отменить в любой момент кнопкой Отмена.

Выпадающий список задач отображает команды в виде дерева: Категория - Подкатегория - Команда. Категории показаны значком папки, команды - значком терминала. При наведении на команду появляется подсказка с описанием и параметрами.

Если команда содержит параметры (%param1%, %param2%), при нажатии «Выполнить» откроется диалог ввода - для каждого параметра отображается название и текстовое поле. Окно подгоняется под содержимое, клавиша Enter подтверждает ввод.

При двойном клике на строке результата открывается окно вывода. Очень большой вывод сокращается для отображения; для дальнейшей работы сохраните результат в файл. Если команда ещё выполняется - вывод обновляется в реальном времени.

Интерактивный ввод во время выполнения

Если команда ждёт ввода (пароль, подтверждение, текст), окно результата предоставляет поле ввода и кнопку Отправить. Введите текст и нажмите Enter или кнопку - текст будет отправлен в активную SSH-сессию выбранного устройства. Отправленный ввод отображается в области вывода с пометкой [stdin].

Для приглашений вида «Press Enter» / «Нажмите Enter» достаточно нажать Enter в пустом поле - будет отправлен перевод строки. Пустой ввод отображается как [stdin] ⏎.

Поле ввода работает только для SSH-команд и доступно, пока команда выполняется. После завершения команды (статус «Успех»/«Неудача»/«Отменено»/«Потеря связи») поле и кнопка скрываются. При открытии окна для уже завершённой команды поле ввода также скрыто.

Правый клик по таблице результатов:

  • Сохранить текущий результат - сохранить вывод выбранного устройства в файл
  • Сохранить все результаты - экспортировать все результаты в табличный файл
  • Очистить все - удалить все строки из таблицы

Передача файлов (SFTP)

Команды типа SFTP позволяют передавать файлы между вашим компьютером и удалённым сервером. Формат: источник::назначение

./packages/app.rpm::root@192.168.1.10:/tmp/app.rpm

С подстановками:

./packages/%param1%.rpm::%login%@%hostname%:/tmp/%param1%.rpm

Скачивание с сервера:

%login%@%hostname%:/var/log/messages::./logs/

Удалённые: Установка

Шаг потоковой установки выбранных сервисов (SSH, Veyon, VNC) на удалённые хосты через SSH. Ключи (SSH и Veyon) готовятся на локальных шагах и только деплоятся на хосты - повторно генерировать их здесь не нужно.

Интерфейс шага состоит из трёх частей:

  • Слева - дерево хостов с галочками. Отметьте устройства, на которые нужно установить сервисы. Под деревом - метка с перечнем сервисов, выбранных на шаге «Выбор режима».
  • Справа - таблица статусов «Хост × Сервисы». Колонки формируются динамически из выбранных сервисов (SSH / Veyon / VNC). Каждая ячейка отображает иконку статуса:
ИконкаСтатус
⏳Ожидание - хост в очереди, установка ещё не началась
✅Успех - сервис установлен и настроен
❌Ошибка - подробности в детальном логе хоста
⏭Пропуск - сервис не выбран или уже установлен
⏹Остановлено - установка прервана пользователем
  • Снизу - общий лог с краткими сообщениями о ходе установки (по одной строке на событие).

Кнопки управления:

  • Установить - запустить потоковую установку на отмеченных хостах. Перед запуском мастер проверяет готовность ключей (SSH и Veyon) - если ключ не подготовлен, запуск блокируется с подсказкой вернуться на соответствующий локальный шаг.
  • Прервать - остановить установку. Текущие операции на хостах завершаются корректно, оставшиеся хосты помечаются как остановленные.

Двойной клик по строке таблицы открывает модальное окно с детальным логом по конкретному хосту - там фиксируются все команды, вывод и ошибки для каждого сервиса отдельно.

Состав операций по каждому сервису (выполняются последовательно на каждом хосте в рамках одного SSH-соединения):

СервисЧто выполняется на хосте
SSHSFTP-деплой публичного ключа в authorized_keys для беспарольной авторизации
VeyonИмпорт публичного ключа через veyon-cli authkeys import, установка метода аутентификации (key-file), регистрация и перезапуск Veyon Service, открытие портов firewall
VNCУстановка и настройка выбранного сервера: kmsvnc, x11vnc или KRFB. Мастер задаёт пароль, настраивает запуск и проверяет подключение.
Установка выполняется параллельно - количество потоков берётся из настроек сети приложения. Для каждого хоста открывается одно SSH-соединение, внутри которого сервисы устанавливаются последовательно. Требует root-доступа на хостах (прямой вход под root или обычный пользователь с sudo - см. настройки SSH).

IP-сканер

Инструмент для поиска устройств в сети. Открывается через Инструменты - Сканер хостов.

Как пользоваться

  1. Укажите сеть или диапазон адресов. Поддерживаются форматы:
    • CIDR: 192.168.1.0/24
    • Полный диапазон: 192.168.1.1-192.168.1.254
    • Короткий диапазон: 192.168.1.1-15
    • Одиночный IP: 192.168.1.100
  2. Выберите режим сканирования: ICMP-ping или проверка портов
  3. При проверке портов - настройте список портов
  4. При необходимости включите определение MAC-адресов и фильтр «только доступные»
  5. Ползунком «Потоки» задайте количество параллельных потоков сканирования (1–128, степень двойки). Значение сохраняется между запусками, по умолчанию 32
  6. Нажмите Сканировать
  7. Отметьте нужные устройства и нажмите Добавить выбранные хосты

Результаты группируются по подсетям и показывают IP-адрес, открытые порты, MAC-адрес и статус доступности. В строке состояния отображается прогресс сканирования: сколько адресов проверено и сколько активных хостов найдено. Правым кликом по таблице можно отметить сразу все устройства одного типа — меню показывает найденные типы с количеством.

Пингер

Инструмент для детальной диагностики сети через ICMP-ping с графиком задержки в реальном времени. Открывается через меню Инструменты - Пингер. В отличие от автоматического мониторинга доступности (см. Мониторинг доступности), пингер выполняет настоящий ICMP-ping и показывает динамику задержки по времени. Можно следить за несколькими хостами сразу - каждый рисуется своей линией.

Как пользоваться

  1. Введите IP-адрес или hostname в поле и нажмите Добавить (или отметьте хосты галочками в списке)
  2. Нажмите Старт - опрос идёт раз в секунду по каждому отмеченному хосту
  3. Кнопка Пауза замораживает опрос с сохранением графиков, Продолжить дописывает в ту же сессию

Цвет линии на графике зависит от задержки:

  • Зелёный - до 50 мс
  • Жёлтый - 51-200 мс
  • Красный - более 200 мс

Каждый хост получает свой цвет линии (можно закрепить через «Поменять цвет» в контекстном меню - цвет сохраняется между запусками). Время на оси подписано человекочитаемо: секунды, потом мм:сс, потом чч:мм:сс. Хранится вся сессия, вид следует за последними пятью минутами.

Управление списком

  • Горячее добавление и удаление - хосты добавляются и удаляются прямо во время опроса, остальные графики не прерываются
  • Контекстное меню списка - «Поменять цвет», «Отметить все», «Снять отметки», «Удалить», «Очистить графики»
  • Удаление клавишей Delete - убрать выбранный хост из списка

Карта сети

Откройте Инструменты → Карта сети, задайте сеть или диапазон и запустите поиск. Карта помогает увидеть найденные устройства и маршруты до них. При отмене уже найденные результаты остаются на экране.

  • Быстрый режим проверяет несколько представителей подсети и предполагает общую часть маршрута для остальных.
  • Точные маршруты проверяет путь до каждого найденного адреса и занимает больше времени.
  • Проверить маршрут уточняет путь до выбранного устройства.
  • В свойствах узла можно задать своё название; досканирование сохраняет ручное расположение узлов.

Сплошная линия обозначает наблюдаемый переход, пунктир — неизвестный участок или предположение, точки — принадлежность подсети. Карта показывает сетевые маршруты, а не схему физических кабелей. Если устройство не отвечает на проверку, это ещё не доказывает, что оно выключено: ответы могут быть запрещены настройками сети.

Видеоредактор

Для первого монтажа начните с инструкции «Как пользоваться» ниже: добавьте запись, обрежьте ненужное, сохраните проект и экспортируйте видео.

Редактор открывается отдельным немодальным окном. Кнопка экспорта находится справа вверху; сохранение проекта доступно в меню Проект и по Ctrl+S. В центре два независимых просмотра: исходник из медиапанели и результат таймлайна. Три кнопки-иконки сверху выбирают оба просмотра рядом, только исходник или только монтаж; включена всегда одна. Те же команды доступны в Вид → Просмотры. Режим, геометрия и положение разделителей сохраняются отдельно от монтажа.

Области кадра по умолчанию имеют одинаковые размеры. Под каждым просмотром находятся собственные перемотка и управление воспроизведением; кнопки нарезки и удаления остаются в той же строке под монтажом. Кнопки действий используют иконки, названия показаны в подсказках. Настройки звука слева от таймлайна видны постоянно; сгруппированные команды доступны напрямую без переключателя расширенных инструментов.

Инструмент для нарезки и склейки записей на таймлайне. Открывается через Инструменты - Видеоредактор. Разрез, перемещение, trim, громкость, Mute и изменения текстов поддерживают кнопки отмены/повтора и горячие клавиши Ctrl+Z / Ctrl+Y. Один жест мышью — один шаг истории; последовательный ввод текста объединяется до паузы 500 мс или перехода к другой операции.

При фокусе в поле ввода клавиши S/I/O, пробел, Delete и стрелки редактируют поле; Ctrl+Z/Ctrl+Y используют его локальную историю. Команды отмены/повтора монтажа доступны в Проект → История.

В медиапанели доступны поиск по имени/пути, фильтры, естественная сортировка и множественный выбор. Добавить на таймлайн выкладывает выбранные файлы в видимом порядке одним шагом Undo; без выбора — все видимые. «Добавить все» пропускает уже использованные файлы. Не завершившие анализ файлы перечисляются в общем статусе; повторите действие после анализа. Удаление из проекта не удаляет файлы с диска.

Выберите импортированный файл для просмотра в окне Исходник; двойной щелчок также открывает этот просмотр, если он скрыт. Его курсор и In/Out независимы от таймлайна, монтажные подписи в исходнике не показываются. Выберите вход/выход и нажмите иконку Добавить фрагмент In/Out на таймлайн. Точные границы и выбор потоков раскрываются иконкой шестерёнки. Выбор потоков действует на все фрагменты этого файла; более короткий видеопоток не заменяет уже используемый материал без правки границ. Запуск одного просмотра ставит другой на паузу. Перед экспортом сводка показывает контейнер, кодеки, длительность, размер и FPS; объём оценивается только при известном битрейте, с явной оговоркой о накладных расходах контейнера.

Поле таймкода принимает секунды, ЧЧ:ММ:СС.мс или ЧЧ:ММ:СС:кадры. Стрелки вверх/вниз переходят по стыкам; Ctrl+колесо меняет масштаб у курсора. Привязка учитывает стыки, In/Out и плейхед; Alt временно отключает её. Шаг соответствует рациональному CFR проекта; для исходного VFR это приближение. История ограничена 100 шагами и 32 МиБ сжатых снимков; старые команды вытесняются.

Меню Монтаж → Звук задаёт нарастание/затухание и коэффициент нормализации. Измерение исходного пика выполняется в фоне и сохраняет коэффициент для уровня −1 dBFS (усиление ограничено ×100); громкость клипа и мастер умножаются на него. Лимитер явно ограничивает пики микса до 0.95 без автоматического подъёма уровня; индикатор показывает декодированный уровень и клиппинг. Кроссфейду двух соседних аудиоклипов нужен запас материала с обеих сторон; другие клипы не сдвигаются.

Созданный текстовый блок виден на фиолетовой T-дорожке над видео даже с пустой строкой или пробелами. Пробелы в начале и конце надписи сохраняются. Дорожка отсутствует, пока текстовые блоки не созданы; очистка содержимого уже созданного блока её не скрывает. Перетаскивайте блок для переноса по времени, левый/правый край — для изменения начала/конца. Выбор блока показывает его настройки справа; Delete удаляет только текст. Перекрывающиеся надписи размещаются в отдельных строках. Изменения поддерживают Undo/Redo и сохраняются в проекте. При вырезании времени интервалы текста сдвигаются вместе с монтажом.

Обрезка за края работает для видео, аудио и текста: наведите мышь на левый или правый край блока, дождитесь горизонтального курсора изменения размера и тяните. У связанной V+A-пары оба блока обрезаются вместе, в том числе при перетаскивании края аудио. После разделения меняется только тот блок, за край которого тянут. У коротких фрагментов также доступны оба края, а середина остаётся для перемещения. Заблокированная дорожка или связанная пара не обрезается.

Титры также имеют числовые начало/конец (конец 0 — до конца проекта), многострочный ввод и дублирование. Привязанные к клипу титры показываются на таймлайне в абсолютном времени, их границы остаются внутри клипа. Явный TTF/OTF или разрешённый файл выбранного семейства используется общим движком предпросмотра и экспорта; отсутствующий шрифт даёт ошибку. Размер и отступы заданы в пикселях холста.

Чтобы работать с видео и звуком отдельно, нажмите ПКМ по клипу и выберите Разделить видео и аудио или используйте Ctrl+Shift+U. Метка V+A исчезнет, части можно перемещать и удалять независимо. Команды Удалить только звук и Удалить только видео доступны сразу для связанной пары: они сохраняют вторую часть и временные позиции остальных клипов. Эти же действия есть в меню Монтаж.

Экспорт поддерживает профили H.264 с CRF/preset, диапазон In/Out, выбранный клип и пробные 10 секунд от курсора. Для звука доступны WAV (PCM), MP3, AAC и M4A. Большой монтаж готовится частями: до 24 входов одновременно, FFV1 + PCM без промежуточных потерь кодирования; перед началом проверяется консервативная оценка временного диска. Финальное кодирование выполняется один раз.

Маркеры и фрагменты хранят именованные точки/интервалы, цвет и заметки; удаление времени сдвигает маркеры вместе с монтажом. Экспорт серии фрагментов показывает имена и коллизии до запуска, выполняет файлы последовательно и по умолчанию пропускает существующие. Кнопка отменяет текущий файл; Проект → Отменить серию останавливает очередь. Диагностика последней ошибки экспорта доступна в верхнем меню без путей и содержимого подписей.

В окне камер действие Готовые записи в видеоредакторе передаёт завершённые локальные файлы и достоверные подписи/время, оставляя активную запись работать. В удалённой записи действие Скачать и открыть в редакторе доступно после остановки: скачанный файл проверяется до публикации и импорта.

В готовой сборке медиадвижок уже включён. Проверить его работу можно через Помощь → Инструменты → FFmpeg: окно показывает доступные форматы, фильтры и результаты пробного кодирования.

Видеослои и преобразования. Меню «Монтаж → Дорожки» добавляет видеослои и меняет их порядок (снизу вверх), видимость и блокировку. Для аудиодорожек доступны Mute/Solo и ducking по сигналу другой дорожки с порогом, степенью сжатия, атакой и возвратом. Преобразования выбранного видео задают непрозрачность, масштаб, положение долями холста, crop, поворот и появление/исчезновение. Скорость 0.5×/1×/2× применяется вместе со связанным звуком; соседние клипы не сдвигаются. Видеопереход требует запаса материала и создаёт верхний слой; звук сводится отдельным аудиокроссфейдом.

Титры и раскадровка. Титр можно привязать к выбранному клипу, отвязать, оформить пресетом или задать безопасные отступы 5%. После команды «Переместить титр в предпросмотре» перетащите его в области кадра: отступы меняются одним шагом Undo. «Маски областей кадра» закрывают нормированный прямоугольник чёрным на заданном интервале. «Раскадровка монтажа» готовит до 16 итоговых кадров на страницу и позволяет перейти к маркеру/стыку. Шаблоны {source}, {timecode}, {recorded_at} вставляют значения выбранного кадра в редактируемую подпись; время записи берётся только из достоверных метаданных камер.

Proxy временно отключены. Для Linux VAAPI/QSV в дополнительных параметрах экспорта можно явно указать DRM render-устройство; проверка использует тот же путь, что и кодирование.

Таймлайн

  • Дорожки видео (V) и звука (A)
  • Видеоклип со звуком - связанная пара, режется синхронно
  • Лента кадров на видеоклипах, волна на аудио

Текст

  • Блоки в углах кадра со своим шрифтом и цветом
  • Подложка: цвет, прозрачность, отступы
  • Позиция ползунками X и Y

Звук

  • Громкость и Mute у каждого клипа
  • Звук берётся с A-дорожек; параллельные клипы микшируются
  • Громкость клипа и мастер применяются одинаково в preview и результате

Экспорт

  • MP4/MKV без перекодирования или с ним
  • Живой прогресс со скоростью; оценка остатка времени при выбранном выходном FPS, 100% после проверки результата
  • Кнопка «Отмена» останавливает экспорт

Как пользоваться

  1. Импортируйте файлы - они появятся в списке с миниатюрой первого кадра (у аудио - форма волны, у видео со звуком - пометка моно/стерео). Длительность и разрешение подставятся по окончании анализа
  2. Выложите нужное на таймлайн через меню списка «Добавить на таймлайн» или «Добавить все на таймлайн» - первый файл сразу покажет кадр в окне просмотра
  3. Переместите курсор и нажмите иконку Разрезать или S. Выберите ненужный фрагмент и нажмите иконку Удалить или Delete: связанная V+A-пара удаляется со сдвигом, отдельный блок — с сохранением времени других дорожек. Разрез обрабатывает медиаклипы под курсором на всех дорожках; на границе клип повторно не режется
  4. Нажмите иконку Добавить текст, введите подпись, выберите угол, размер и оформление. Изменения сразу видны в окне монтажа без повторного кодирования видео. Время показа, точные отступы и многострочный ввод раскрываются шестерёнкой в блоке текста
  5. Нажмите Экспорт и выберите файл результата. Кнопка «В начало» и клавиша Home возвращают в начало таймлайна

Меню Проект сохраняет монтаж в отдельный файл .dnovideo: исходники, их расположение, границы клипов, звук, связи, тексты и маркеры. Ctrl+S сохраняет проект, Ctrl+Shift+S выбирает новое имя; Ctrl+O открывает проект, Ctrl+N создаёт новый. Звёздочка в заголовке означает несохранённые изменения. Экспорт создаёт готовый медиафайл и не заменяет сохранение проекта.

После сбоя доступно Проект → Восстановить после сбоя. Копии создаются отдельно от основного файла; восстановленный монтаж нужно сохранить. Для перемещённых записей используйте Заменить исходник или Перепривязать папку исходников: клипы и их идентификаторы сохраняются, слишком короткая или неподходящая запись отклоняется. Недоступные исходники перечисляются перед экспортом.

ПКМ в окне просмотра предлагает кадр исходника без обработки и кадр монтажа с обработкой: холст, подписи и чёрные промежутки сохраняются как в preview. PNG извлекается в фоне; отмена доступна в том же меню. Ошибка или отмена сохраняют прежний файл.

Простая нарезка и склейка со связанным звуком воспроизводятся напрямую из исходников, включая чёрные промежутки. Перемотка не запускает промежуточное кодирование. Текст накладывается в окне просмотра и обновляется сразу. Для сложного монтажа со слоями, эффектами, самостоятельным аудиомиксом или изменённым холстом готовится ограниченный диапазон общим движком экспорта; стадия подготовки видна в окне. Изменение только текста не перезапускает эту подготовку.

Проект → Параметры проекта → Холст и FPS задаёт размер, рациональный FPS (например, 30000/1001) и вписывание с полями либо заполнение с обрезкой. При заданной одной стороне вторая вычисляется по пропорциям.

Delete удаляет связанный V+A-фрагмент со сдвигом всех дорожек, а отдельный видео-, аудио- или текстовый блок — с сохранением остальных временных позиций. Shift+Delete всегда сохраняет промежуток. Для явного вырезания времени используйте Удалить фрагмент со сдвигом в контекстном меню. Точную числовую правку Start/In/Out/Duration открывает Монтаж → Границы выбранного клипа. Справка остальных клавиш находится в верхнем меню.

Выбор режима экспорта

Для аппаратного кодирования выберите режим С перекодированием H.264/H.265, затем поле Кодирование: процессор, NVIDIA NVENC, Intel QSV, AMD AMF или Linux VAAPI. При открытии окна варианты проходят короткое пробное кодирование в фоне. В обоих списках доступны только успешно проверенные на этой машине кодировщики; остальные отключены, причина указана в подсказке. H.264 и HEVC проверяются отдельно. Проверка повторяется при смене устройства и новом открытии окна. CRF, битрейты и параметры устройства раскрываются кнопкой Дополнительные параметры.

РежимКогда использовать
Без перекодированияПростая склейка без текста и без изменения громкости - быстро, без потери качества
С перекодированиемНужен для текста, изменения холста/FPS, пауз, отдельного звука, громкости и Mute; сохраняет расположение всех клипов
Copy недоступен, если правки или параметры потоков нельзя сохранить без перекодирования. Его границы зависят от ключевых кадров. Возможности FFmpeg проверяются в фоне; выбранный кодировщик проходит короткую пробу перед экспортом. Существующий результат заменяется только после подтверждения и успешной проверки нового файла.

Битые файлы

Для разработчиков доступна отдельная проверка из корня исходников: python -m src.diagnostics.video_editor_check report.json --offscreen. Она использует временный профиль, открывает главное окно и два редактора, проверяет темы, доступность Qt, сохранение проекта, пробный экспорт и закрытие. Рядом с JSON сохраняется снимок окна; настройки пользователя не меняются. Проверку физического звука и скринридера выполняет оператор.

  • Ремонт контейнера (контекстное меню файла) создаёт отдельную исправленную копию без перекодирования и переключает ссылку в проекте; оригинал и старые бэкапы остаются на месте, перепривязка отменяется через Undo
  • Повторить анализ - перезапустить определение длительности и разрешения (например, после установки ffmpeg)
  • Причина ошибки видна в свойствах файла, файл можно переименовать прямо в списке
Подписи включаются в готовое видео при экспорте. Если обработка недоступна, программа сообщает причину; проверить медиадвижок можно в меню «Помощь → Инструменты → FFmpeg».

Камеры ЕЦХД

Окно для просмотра и записи IP-камер видеонаблюдения по протоколу RTSP. Открывается через меню Инструменты - Камеры ЕЦХД.

Дерево камер

Камеры организованы в виде иерархического дерева: Адрес - Кабинет - Камера. Для каждой камеры отображается:

Просмотр потока

Правый клик по камере - Посмотреть открывает RTSP-поток во внешнем плеере. Плеер выбирается в настройках:

  • VLC - по умолчанию
  • mpv
  • ffplay

Выбранный плеер должен быть установлен в системе. Убедитесь, что vlc, mpv или ffplay доступен в переменной окружения PATH.

Запись потока

Правый клик по камере - Записать запускает запись RTSP-потока в файл формата MKV без перекодирования (поток копируется как есть). Запись выполняется встроенным медиадвижком; отдельно устанавливать ffmpeg для неё не нужно. Записи не удаляются автоматически: следите за свободным местом и удаляйте ненужные файлы самостоятельно.

  • Остановить — корректно завершить запись и закрыть файл
  • Остановить все в группе - останавливает все записи внутри адреса или кабинета
  • Остановить все - останавливает все активные записи
Если связь с камерой прерывается во время записи, программа автоматически возобновляет запись через 3 секунды после восстановления доступности камеры. Переподключение работает, пока запущена программа. После полного выхода и нового запуска запись нужно включить заново.

Связки учётных данных

Единственный источник учётных данных SSH - именованные связки (логин и пароль). Открываются через Настройки → Подключение → Данные для входа. Пароли шифруются при сохранении в файл настроек. Каждому устройству можно назначить свою связку (в диалоге устройства, в мастере настройки, при импорте диапазона IP); хосты без собственной связки используют глобальную связку по умолчанию.

Выполнение команд через sudo

Если на целевых машинах SSH-логин выполняется не под root, а под обычным пользователем с правами sudo (например, членом группы wheel), включите настройку «Использовать sudo для non-root логина» - глобально или для отдельного устройства. При этом:

  • Команды, содержащие sudo, автоматически получают пароль - программа перехватывает приглашение [sudo] password for ...: и подаёт пароль из связки учётных данных устройства (или глобальной связки по умолчанию)
  • Команды без sudo получают его автоматически в начале (если для устройства включено sudo)
  • Плейсхолдер %sudo% в тексте команды раскрывается в sudo если sudo включено, иначе в пустую строку - удобно для точечной вставки повышения прав в середину составных команд, например echo x | %sudo%tee /etc/y
  • Установка сервисов в мастере настройки (SSH-ключи, Veyon, VNC) также корректно работает через sudo на non-root хостах

Для отдельного устройства режим sudo задаётся в диалоге редактирования (двойной клик по устройству): «По умолчанию» (наследовать глобальную настройку), «Да» или «Нет». При сохранении с включённым sudo и отсутствующим паролем в связке показывается предупреждение.

Локаль SSH-команд

Перед выполнением SSH-команды программа устанавливает переменные окружения LANG, LC_ALL и LC_CTYPE для корректного вывода кириллицы и локализованных сообщений (заголовки колонок df, free, статусы systemctl, сообщения об ошибках и т.д.). По умолчанию используется ru_RU.UTF-8.

Если на целевой системе указанная локаль не сгенерирована (отсутствует в locale -a), жёсткая установка вызывает предупреждение bash: warning: setlocale: LC_ALL: cannot change locale (ru_RU.UTF-8). В этом случае:

  • Глобально - очистите поле «Локаль» в настройках SSH. Переменные окружения не будут устанавливаться, предупреждение исчезнет
  • Для отдельного устройства - в диалоге редактирования выберите пункт «(отключить)» в поле «Локаль». Экспорт локали будет отключён только для этого хоста
  • Можно также выбрать другую локаль из списка или ввести свою (например, en_US.UTF-8 или C.UTF-8)

Настройка локали для отдельного устройства: «По умолчанию» (наследовать глобальную) или явное значение. Поле с выпадающим списком стандартных локалей и возможностью ввода своего значения.

Приоритет учётных данных

При выполнении команды логин и пароль определяются в следующем порядке:

  1. Связка устройства - если хосту назначена собственная связка учётных данных
  2. Глобальная связка по умолчанию - если собственная связка не выбрана
  3. Значения по умолчанию - логин root, пароль не указан

Аутентификация по ключу

Если пароль не указан, программа пытается использовать SSH-ключ. Поддерживаются ключи Ed25519 (рекомендуется), RSA и ECDSA.

Веб-сервер управления

DNO Tool содержит встроенный веб-сервер, позволяющий управлять устройствами и выполнять команды через браузер - без установки десктоп-приложения на клиентской машине. Для доступа из браузера DNO Tool должен оставаться запущенным на компьютере, где включён сервер.

Возможности веб-интерфейса:
  • Дерево устройств с группами, поиск, массовый выбор
  • Дерево задач из библиотеки команд с поиском
  • Потоковое выполнение команд с выводом результатов в реальном времени (WebSocket)
  • Ввод параметров команды через модальный диалог
  • Режимы отображения устройств: список (с иконками онлайн/оффлайн), иконки, миниатюры (Veyon)
  • Фильтр «Только онлайн» слева от переключателя вида - скрывает недоступные устройства, как в приложении
  • Группировка выбранных устройств по папкам
  • Проверка статуса устройств и живые миниатюры экранов
  • Удалённый рабочий стол прямо в браузере (VNC/Veyon) - без установки VNC-клиента
  • При отсутствии Veyon на машине оператора Veyon-элементы (кнопки команд, миниатюры) автоматически скрываются - остаются только статусы и базовые функции
  • Многопользовательский режим: у каждого пользователя свои задания и выбор устройств
  • Аутентификация по логину/паролю, восстановление сессии после обновления страницы

Запуск и настройка

Откройте Настройки → Удалённое управление → Веб-сервер управления. Диалог позволяет:

  • Включать/выключать сервер кнопкой «Запустить»/«Остановить»
  • Открывать веб-интерфейс в браузере одной кнопкой
  • Задавать адрес и порт прослушивания
  • Управлять пользователями: добавлять, редактировать и удалять учётные записи; у каждого пользователя - свои задания и выбор устройств. Пароли в таблице пользователей скрыты маской и видны только при редактировании ячейки
  • Включать автозапуск сервера при старте приложения
  • Настраивать размеры пулов потоков (миниатюры/статусы и команды) ползунками из набора 1, 2, 4, 8, 16, 32, 48, 64

После изменения настроек сервер автоматически перезапускается, если он был запущен.

Безопасность. По умолчанию сервер слушает все интерфейсы (0.0.0.0). Обязательно задайте надёжные пароли учётным записям перед запуском в сети. Сервер выполняет SSH/SFTP-команды от имени учётных данных, заданных в настройках и устройствах приложения.

Аутентификация и сессии

Доступ к веб-интерфейсу возможен только для аутентифицированных пользователей. Сервер поддерживает два способа входа:

  • Форма входа в браузере - при открытии страницы пользователь вводит логин и пароль, сервер создаёт сессию и выдаёт токен
  • HTTP Basic - логин/пароль передаются в заголовке каждого запроса (для скриптов и внешних клиентов)

Каждая вкладка браузера получает свой идентификатор сессии: выбор устройств сохраняется на сервере и восстанавливается после обновления страницы или кратковременной потери связи. Токен хранится в браузере и используется для запросов изображений (иконки, миниатюры), куда браузер не отправляет заголовок Basic.

Многопользовательский режим. В диалоге настройки задаётся список учётных записей. Каждый пользователь видит только свои задания - доступ к чужим заданиям запрещён. Это позволяет работать нескольким администраторам с одного сервера одновременно, не мешая друг другу.

Veyon: мониторинг и доступ

Интеграция с Veyon позволяет просматривать экраны устройств в виде живых миниатюр прямо в списке устройств, а также подключаться к удалённым машинам для просмотра и управления. В отличие от записи экрана, миниатюры обновляются в реальном времени через WebAPI Veyon (HTTP REST, порт 11080).

Требования для работы:
  • Veyon установлен на машине оператора (veyon-cli доступен в PATH)
  • Veyon Service запущен на машине оператора
  • WebAPI-плагин включён в Veyon Configurator (порт 11080 по умолчанию)
  • Создан ключ аутентификации и выбран в настройках Veyon
  • На целевых машинах Veyon Service запущен (для просмотра и управления)

Живые миниатюры экранов

Миниатюры отображаются прямо в списке устройств вместо стандартных иконок. Управление режимом - через панель инструментов списка устройств:

  • Кнопка-тумблер миниатюр - включает/выключает режим живых миниатюр
  • Ползунок размера - регулирует размер иконок/миниатюр от 32 до 512 пикселей
  • Кнопка «только онлайн» - фильтрует список, показывая только доступные устройства

Если на машине оператора Veyon не установлен или его сервис остановлен, кнопка миниатюр и переключатель стиля скрываются с панели инструментов - остаются только фильтр онлайн и ползунок размера. В режиме миниатюр без Veyon вместо снимков экрана показываются иконки онлайн/оффлайн, окрашенные по реальному статусу устройств. Когда Veyon становится доступен (запущен сервис), скрытые элементы автоматически возвращаются - приложение проверяет состояние каждые 60 секунд.

Миниатюры имеют формат 16:9, центрируются на прозрачном квадрате. Обновление происходит по таймеру для каждого устройства индивидуально с заданным интервалом и небольшим разбросом для равномерной нагрузки. При изменении размера ползунком миниатюры мгновенно перерисовываются из уже загруженного изображения - без ожидания следующего обновления.

Доступны два стиля отображения миниатюр (настраивается в диалоге Настройки Veyon на вкладке «Миниатюры»):

  • monitor - миниатюра вписана в рамку монитора (по умолчанию)
  • plain - голая картинка 16:9 без рамки

Миниатюры запрашиваются только для онлайн-устройств. При потере связи миниатюра автоматически очищается, а при восстановлении - возобновляется. При группировке устройств по папкам миниатюры корректно отображаются внутри каждой группы.

Если компьютер включён, но сервис Veyon на нём не работает или не установлен, его миниатюра окрашивается в оранжевый цвет - сразу видно, на какие машины нельзя заглянуть, не путая их с выключенными (красными) и рабочими (зелёными). Работает и в приложении, и в веб-интерфейсе.

По умолчанию миниатюры захватываются только с устройств, отвечающих на обычный пинг. Такое поведение можно изменить переключателем «Учитывать обычный пинг» в диалоге Настройки Veyon на вкладке «Миниатюры». Если переключатель выключен, захват выполняется и с устройств, не отвечающих на обычный пинг (бывает, когда их файрвол закрывает служебные порты, но Veyon доступен): рабочий экран при этом отображается как обычно. Если же недоступны и обычный пинг, и Veyon - устройство по-прежнему красное.

  2. Меню Veyon - Просмотр экрана или Управление

Подключение выполняется через veyon-cli remoteaccess view|control <host>. При закрытии DNO Tool все активные окна Veyon автоматически останавливаются.

Веб-интерфейс также поддерживает удалённый рабочий стол прямо в браузере - без установки VNC-клиента. Подробнее - в разделе Удалённый рабочий стол.

Команды Veyon (блокировка экрана и ввода, перезагрузка, выключение, завершение сеанса, вход пользователя, открытие сайта, запуск программы, текстовое сообщение, включение по сети) доступны в контекстном меню устройства, на панели инструментов над списком и в веб-интерфейсе. На панели и в веб-интерфейсе команды применяются сразу ко всем выбранным устройствам.

Контекстное меню устройства разделено на два подменю: «Управление» (включение по сети, перезагрузка, выключение, завершение сеанса, вход пользователя - через SSH и DBus, показывается всегда) и «Veyon» (просмотр экрана, управление, блокировки, вход пользователя через Veyon, сообщения, перезапуск сервиса - скрывается целиком при отсутствии Veyon). Команда «Выход пользователя» в подменю «Veyon» завершает сеанс штатно через Veyon WebAPI, а устойчивый вариант «Завершить сеанс» в подменю «Управление» работает через SSH на уровне системы и не требует Veyon.

Команда «Вход пользователя» в подменю «Управление» выполняет удалённый вход через системный DBus-сервис org.mos.auth (доступен на ROSA Linux/MOS при настроенной подсистеме mos-auth). Сервис работает только пока на хосте активен экран входа SDDM и никто не вошёл в систему - при ошибке входа показывается конкретная причина (кто залогинен, выключена ли подсистема mos-auth, какая тема SDDM используется) и способ устранения.

Кнопки питания (включение по сети, перезагрузка, выключение, завершение сеанса) больше не зависят от Veyon и всегда видны - даже если Veyon не установлен или сервис остановлен.

При отсутствии Veyon на машине оператора подменю «Veyon» в контекстном меню автоматически скрывается - остаются только функции из «Управления», не зависящие от Veyon. Меню Настройки Veyon остаётся доступным всегда: через него можно диагностировать состояние, запустить остановленный сервис и настроить ключи.

Команда «Перезагрузить сервис» выполняет по SSH systemctl restart veyon на всех выбранных устройствах и доступна в тех же местах, что и остальные команды Veyon, включая панель инструментов окна удалённого доступа VNC. Удобна при зависании Veyon Service на хостах или после изменения его настроек.

Удалённый рабочий стол

Веб-интерфейс DNO Tool позволяет подключаться к экрану устройства прямо из браузера - без установки VNC-клиента. Поддерживаются два режима, которые определяются автоматически для каждого устройства:

  • VNC - прямой доступ к x11vnc на хосте. Полноценный удалённый рабочий стол: буфер обмена, изменение размера сессии, все кодеки. Рекомендуемый режим
  • Veyon - доступ через Veyon с аутентификацией по ключу. Ограниченный режим: недоступны буфер обмена и изменение размера сессии. Используется, если на хосте не установлен x11vnc, но есть Veyon

При открытии удалённого рабочего стола интерфейс проверяет доступность обоих режимов и выбирает VNC, если он доступен, иначе - Veyon. Если недоступны оба - подключение не выполняется. Вторым VNC-сервером наряду с x11vnc может быть krfb - см. KRFB - общий экран через KDE.

Как подключиться

  1. В веб-интерфейсе переключитесь в режим «Миниатюры»
  2. Наведите курсор на миниатюру устройства - в правом верхнем углу появится кнопка монитора
  3. Нажмите на неё - откроется новое окно с удалённым рабочим столом
Кнопка удалённого доступа появляется только если на машине оператора установлен Veyon (и включён RFB-мост) или на хосте доступен VNC-порт.

Панель управления

Окно удалённого рабочего стола содержит вертикальную панель управления слева (в стиле Proxmox/noVNC). Панель можно перетащить за маркер к любому краю окна - сверху, снизу, слева или справа. Панель автоматически скрывается через 2 секунды бездействия и появляется при наведении курсора.

Питание

  • Выключение и перезагрузка хоста
  • Включение по сети (Wake-on-LAN)

Veyon

  • Блокировка и разблокировка экрана
  • Блокировка и разблокировка ввода
  • Текстовое сообщение пользователю
  • Перезапуск сервиса Veyon на хосте

Буфер обмена

  • Отправка текста на удалённую машину
  • Получение текста из буфера обмена хоста
  • Только в VNC-режиме

Дополнительно

  • Клавиши-модификаторы: Ctrl, Alt, Win (залипание)
  • Отправка Tab, Esc, Ctrl+Alt+Del

Настройки

  • Совместный сеанс, обрезка по окну, масштабирование
  • Кодек (авто/tight/zlib/raw), качество и сжатие

Прочее

  • Полноэкранный режим
  • Отключение от хоста

Подсказки

Все кнопки панели управления и основного интерфейса снабжены всплывающими подсказками. Используются собственные подсказки в тёмной теме вместо стандартных браузерных - они появляются с небольшой задержкой и плавно скрываются при уходе курсора.

Ограничения Veyon-режима. При подключении через Veyon недоступны буфер обмена и изменение размера сессии - Veyon пропускает только базовые сообщения VNC. Для полнофункциональной работы установите x11vnc на хосты (через мастер настройки или диагностику).

KRFB - общий экран через KDE

Второй способ общего экрана - krfb (KDE Remote Desktop Server): на хосте запускается krfb в пользовательском сеансе KDE, доступ - по VNC-паролю. Выбор сервера - селектором «x11vnc | krfb» вверху окна настроек и на первом шаге мастера настройки (мастер при необходимости предложит установить krdc и krfb на ваш компьютер). VNC-пароль общий для обоих серверов; повторный запуск установки применяет новый пароль к уже настроенным хостам.

Доступ к экрану

  • Подменю «VNC (KRFB)» в контекстном меню хоста

Диагностика

Окно «Диагностика» (меню Помощь → Инструменты → Диагностика) помогает быстро понять, что работает на выбранных устройствах, а что нет - без необходимости подключаться к каждому вручную.

Что проверяет

КомпонентЧто проверяется
SSHМожно ли подключиться и выполнить команду, а также какие права sudo доступны (root, NOPASSWD, sudo с паролем или нет sudo)
VeyonЗапущен ли Veyon на устройстве и возможно ли подключение к нему
VNCДля выбранного в настройках способа общего экрана (x11vnc или krfb): какой бекенд фактически активен на устройстве, доступен ли его порт, автозапуск и принимает ли пароль

Как пользоваться

  1. Отметьте, что именно хотите проверить (SSH, Veyon, VNC - по умолчанию выбрано всё)
  2. Отметьте устройства в списке
  3. Нажмите Запустить - все проверки выполняются одновременно
  4. В таблице появится результат: ✅ работает, ❌ ошибка, ⚠ предупреждение и т. п.
  5. Двойной клик по строке открывает подробный отчёт по конкретному компьютеру

Результаты сгруппированы по компонентам, так что видно сразу - например, что SSH работает, а VNC нет. Состав колонок меняется в зависимости от того, какие компоненты вы выбрали.

Диагностика работает всегда - даже если Veyon не установлен на вашей машине. Для проверок используются те же логин, пароль и ключ, что и при обычном выполнении команд.

В редакторе можно передавать команды между экземплярами DNO Tool через текст в кодировке Base64:

  • Экспорт - выбрать команду, нажать «Экспорт», скопировать код
  • Импорт - вставить код Base64. Программа определит формат:
    • Полная команда - заменяет текущую
    • Список шагов - добавляет к текущей команде

Файловый импорт и экспорт библиотеки

  • Файл - Задачи - Экспортировать команды - сохранить всю библиотеку в JSON-файл
  • Файл - Задачи - Импортировать команды - загрузить команды из JSON-файла. Откроется диалог с превью изменений и выбором режима: Обновить (добавить новое, совпадающие имена разрешить вручную в диалоге конфликтов) или Заменить (целиком пересобрать библиотеку из файла)
Важно! Изменения в редакторе сохраняются в ~/.dno-tool/commands.json. При обновлении приложения файл не перезаписывается автоматически - используйте импорт для обновления библиотеки команд.

Пользовательские панели

Собственные панели с кнопками частых команд - для действий, которые выполняются в один клик. Кнопка панели запускает свою команду на тех же отмеченных хостах, что кнопка Выполнить (включая хосты удалённых нод). Показ и скрытие каждой панели - галочками в подменю Вид - Панели, настройка - пункт Настроить панели... там же.

Панели

  • Несколько именованных панелей сразу
  • Название в начале тулбара (галочка «Показывать название»)
  • Общий размер иконок: 16-64 px

Кнопки

  • Каждая кнопка - команда из библиотеки
  • Выбор команды из дерева с иконками
  • Своя иконка у каждой кнопки

Редактор

  • Настройки панели и кнопок - в отдельных рамках
  • Кнопка «Применить» без закрытия окна
  • Двойной клик - смена команды кнопки

Как создать

  1. Откройте Вид - Панели - Настроить панели...
  2. Создайте панель: задайте название, размер иконок и галочку «Показывать название»
  3. Добавьте кнопки: для каждой выберите команду из дерева и подберите иконку (есть поиск и предпросмотр)
  4. Нажмите Применить - панели сохранятся без закрытия окна, ОК - сохранить и закрыть
  5. Включите панель галочкой в Вид - Панели

Несколько площадок: ноды

Нода — другой запущенный экземпляр DNO Tool со своим списком компьютеров. Подключение нод позволяет работать с устройствами нескольких площадок из одного окна.

  1. На подключаемом компьютере откройте Настройки → Данные → Ноды и получите ключ доступа и порт.
  2. В том же окне на своём компьютере добавьте ноду: название, адрес, порт и её ключ доступа.
  3. Сверьте отпечаток ключа с оператором площадки и проверьте соединение.
  4. Включите отображение нод в главном окне. Отмечайте нужные устройства для выполнения команд.

Ключ доступа передавайте только тем, кому разрешено управление площадкой. Доступность устройств и миниатюры зависят от соединения с их нодой; настройки источника миниатюр задаются на ней.

Если что-то не работает

СитуацияЧто проверить
Нет командЗагрузите библиотеку в мастере или импортируйте commands.json через «Файл → Задачи». Программа и библиотека поставляются отдельно.
Компьютер недоступенПроверьте адрес, SSH-порт, сеть и включение компьютера. Статус доступности не подтверждает правильность логина и пароля.
Отказ в SSH-доступеПроверьте назначенную устройству связку, пароль или SSH-ключ. Для операций администратора проверьте настройку sudo и права пользователя.
Нет изображения экранаПроверьте выбранный источник миниатюр, работающий Veyon/VNC-сервер, порт и пароль. На другой источник программа автоматически не переключается.
Ошибка видеоОткройте «Помощь → Инструменты → FFmpeg». Для камеры дополнительно проверьте адрес потока, учётные данные и свободное место.
Команда ждёт вводаДважды нажмите на результат, прочитайте приглашение и отправьте ответ из поля ввода. Для приглашения нажать Enter отправьте пустую строку.

Для обращения за помощью укажите версию из «Помощь → О программе», систему, последовательность действий и текст ошибки. Перед отправкой журнала уберите пароли и другие закрытые данные.

Импорт и экспорт

Перед переносом на другой компьютер экспортируйте устройства и команды через меню «Файл». Это отдельные списки, а не полная резервная копия: учётные данные, SSH-ключи и другие настройки нужно перенести или настроить отдельно.

Папка пользовательских данных: %USERPROFILE%\.dno-tool в Windows (вставьте путь в адресную строку Проводника), ~/.dno-tool в Linux. Для резервной копии закройте программу и скопируйте эту папку в защищённое место. Исходники видеопроектов и записи камер сохраните отдельно: файл проекта не содержит сами видеозаписи.

Устройства

  • Экспорт - Файл - Хосты - Экспортировать список - сохранить список устройств в JSON-файл
  • Импорт - Файл - Хосты - Импортировать список - загрузить устройства из JSON-файла

Команды

  • Экспорт - Файл - Задачи - Экспортировать команды - сохранить библиотеку команд в JSON-файл
  • Импорт - Файл - Задачи - Импортировать команды - загрузить команды из JSON-файла (режимы Обновить/Заменить, см. Редактор команд)
  • Обмен командами через Base64 - в редакторе команд можно экспортировать/импортировать отдельные команды в виде текста (см. Редактор команд)

Обновление

Программа может проверять обновления через диалог Помощь - О программе. При открытии диалога проверка выполняется автоматически; если доступна новая версия, появляется кнопка «Обновить».

  • На Windows - скачивается zip-архив с новой версией в папку Downloads
  • На Linux (RPM) - проверяется наличие новой версии на GitHub, показывается уведомление с подсказкой обновить пакет через менеджер пакетов

Также можно отдельно обновить библиотеку команд - commands.json скачивается с последнего релиза на GitHub.

Файл commands.json не входит в поставку! Он скачивается отдельно при установке или обновлении и хранится в ~/.dno-tool/commands.json.
